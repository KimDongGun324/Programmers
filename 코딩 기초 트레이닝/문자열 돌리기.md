# 문자열 돌리기 - 출력 vs 행렬 전치

## 문제
- 문자열 `str`이 주어진다.
- 문자열을 **시계방향으로 90도** 돌려서 출력한다.
- 제한: $1 \le$ `str`의 길이 $\le 10$

**입력**
```
abcde
```

**출력**
```
a
b
c
d
e
```

> **Q. 행렬 계산을 하라는 걸까?**
> 아니다. "90도 돌리기"는 비유일 뿐이고, **문자를 한 글자씩 줄바꿈해서 출력**하면 된다.
> 다만 행렬로 해석해 보면 $1 \times n$ 행벡터를 $n \times 1$ 열벡터로 바꾸는 것과 모양이 같다.

---

## 풀이 1. 한 글자씩 출력 (실전용)

```cpp
#include <iostream>
#include <string>

using namespace std;

int main(void) {
    string str;
    cin >> str;

    for (char c : str) {
        cout << c << '\n';
    }
    return 0;
}
```

- `for (char c : str)`: **range-based for loop** (C++11). 문자열을 앞에서부터 한 글자씩 꺼낸다.
- 인덱스 버전:

```cpp
for (size_t i = 0; i < str.size(); ++i)
    cout << str[i] << '\n';
```

### `'\n'` vs `endl`

| | 줄바꿈 | 버퍼 flush | 속도 |
|---|---|---|---|
| `'\n'` | O | X | 빠름 |
| `endl` | O | O | 반복문 안에서 느림 |

코테에서는 `'\n'`을 쓰는 습관을 들이자. 이 문제는 길이가 10 이하라 차이는 없다.

---

## 풀이 2. 행렬 전치로 표현

문자열을 $1 \times n$ 행렬 $A$로 보고, 전치 $B = A^T$ ($n \times 1$)를 만든 다음 출력한다.

```cpp
#include <iostream>
#include <string>
#include <vector>

using namespace std;

int main(void) {
    string str;
    cin >> str;

    int rows = 1;                 // A의 행 수
    int cols = (int)str.size();   // A의 열 수

    // 1 x n 행렬 A
    vector<vector<char>> A(rows, vector<char>(cols));
    for (int j = 0; j < cols; ++j)
        A[0][j] = str[j];

    // 전치: B = A^T  (n x 1)
    vector<vector<char>> B(cols, vector<char>(rows));
    for (int i = 0; i < rows; ++i)
        for (int j = 0; j < cols; ++j)
            B[j][i] = A[i][j];    // 핵심: 행과 열 인덱스를 바꿈

    // B 출력 (행마다 줄바꿈)
    for (int i = 0; i < cols; ++i) {
        for (int j = 0; j < rows; ++j)
            cout << B[i][j];
        cout << '\n';
    }
    return 0;
}
```

### 전치의 정의

$$B_{ji} = A_{ij}$$

- 코드로는 `B[j][i] = A[i][j]`
- 크기: $m \times n \rightarrow n \times m$

---

## 전치 ≠ 회전

> **주의:** 전치와 90도 회전은 **다른 연산**이다. 이 문제에서는 우연히 결과가 같을 뿐이다.

$A$가 $m \times n$ 행렬일 때:

| 연산 | 인덱스 매핑 | `abcde` 결과 (위→아래) |
|---|---|---|
| 전치 (transpose) | `B[j][i] = A[i][j]` | a b c d e |
| 시계방향 90° | `B[j][m-1-i] = A[i][j]` | a b c d e |
| 반시계방향 90° | `B[n-1-j][i] = A[i][j]` | **e d c b a** |

- 반시계로 돌리면 오른쪽 끝의 `e`가 맨 위로 온다. 그래서 문제에서 **"시계방향"**을 지정한 것이다.
- 일반적인 관계:
  - **시계 90° = 전치 + 좌우 반전** (각 행 뒤집기)
  - **반시계 90° = 전치 + 상하 반전** (행 순서 뒤집기)
- 이 문제는 $m = 1$이라서 $m-1-i = 0$이다. 좌우 반전할 열이 하나뿐이라 전치와 시계 90° 결과가 같아진다.

---

## 복잡도 비교

| 풀이 | 시간 | 추가 메모리 |
|---|---|---|
| 1. 한 글자씩 출력 | $O(n)$ | $O(1)$ |
| 2. 행렬 전치 | $O(n)$ | $O(n)$ |

실전에서는 풀이 1이 낫다. 풀이 2는 개념을 이해하는 용도로 쓰자.

---

## 정리
- "N도 돌리기" 문제는 실제 회전 계산인지, 출력 방향만 바꾸는 건지 먼저 구분하기
- 반복 출력할 때는 `endl` 말고 `'\n'`
- 전치: $B_{ji} = A_{ij}$, 크기 $m \times n \rightarrow n \times m$
- 시계 90° = 전치 + 좌우 반전 / 반시계 90° = 전치 + 상하 반전
- $1 \times n$에서는 전치와 시계 90° 결과가 같음

다음에는 $3 \times 4$ 같은 직사각형 행렬로 전치, 시계, 반시계 세 가지를 직접 구현해서 비교해 볼 예정이다. 셰이더에서 UV를 회전할 때(`uv.yx`, `float2(uv.y, 1 - uv.x)`)도 같은 원리가 적용된다.
